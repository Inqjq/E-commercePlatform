# 渡风电商平台 · 项目进度与上下文速览

> 本文件用于快速理解仓库现状、运行方式与本轮变更，供开发/后续会话参考，避免重复探索消耗 token。
> 项目基线：`docs/渡风电商平台需求分析文档.md`；本文件不替代需求文档，只记录“当前落地状态”。

## 1. 技术栈与架构

| 层 | 技术 |
| --- | --- |
| 后端 | Spring Boot 3.x · JDK 17 · MyBatis-Plus · Flyway · JWT + Redis 会话黑名单 |
| 前端 | Vue 3（`<script setup>`）· Vite · Pinia · Vue Router 4 · Element Plus |
| 数据库 | MySQL 8（云服务器） |
| 缓存 | Redis 7（云服务器） |
| 支付 | 支付宝沙箱（默认模拟回调，`PAY_MOCK_CALLBACK=true`） |

- 包结构：`com.dufeng.<module>`，模块按领域拆分（user / goods / order / payment / merchant / admin / review / cart / address）。
- 分层：`Controller → Service → Mapper`，统一返回 `{ code: 0, message, data }`（`code=0` 成功），全局 `@RestControllerAdvice`。
- 接口前缀：前台 `/api/portal`，商家 `/api/merchant`，平台 `/api/admin`。

## 3. 运行方式

### 后端（本地连云服务器中间件）
```bash
# 连接参数在 backend/start-local.sh（gitignore，不入库），指向云服务器 MySQL/Redis
cd backend && bash start-local.sh          # 等价 mvn spring-boot:run，profile=dev
```
- 数据库连接（host / 库 / 账号见 `start-local.sh`）：MySQL `119.29.167.133:3306`，库 `dufeng`；Redis 同机 `6379`。
- 首次启动 Flyway 自动执行 `V1__init.sql`、`V2__audit_log.sql`、`V3__init_seed_cloud.sql`。

### 前端
```bash
cd frontend && npm install && npm run dev   # http://localhost:5173
```

## 4. 数据库初始化数据（本轮关键变更）

- **原状**：初始化数据写死在 `com.dufeng.config.DataInitializer`（仅 dev，幂等播种账号/类目/品牌/商家/店铺/商品/SKU）。
- **现状**：已删除 `DataInitializer.java`；初始化数据改由 **`V3__init_seed_cloud.sql`** 提供，该脚本是**从云服务器数据库导出**的真实数据（账号、类目、品牌、商家、店铺、15 个商品、SKU），使用 `INSERT IGNORE`（幂等，可重复执行），并保留云库的 BCrypt 密码哈希。
- 生产/云库已有数据时，V3 重复执行不会改动现有数据（`INSERT IGNORE` 直接跳过）。
- 如需重置为空库，只需让 Flyway 依序执行 V1→V2→V3。

> ⚠️ `t_goods` 中 `id=goods-1` 的 `images` 字段原库为异常 JSON（`["url":...]`），前端 `parseImages` 有 try/catch 兜底到 `mainImage`，详情页可正常显示；如需修复可改为 `[{"url":"/img/goods-1.jpg"}]`。
