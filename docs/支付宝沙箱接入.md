# 支付宝沙箱支付接入指南

> 本项目已内置支付宝「电脑网站支付」对接代码（`AlipayService` + `PaymentServiceImpl`），
> 默认走**模拟支付**（可在收银台点“立即支付”直接成功）。
> 要接入**支付宝沙箱真实联调**，只需按下面步骤拿到沙箱密钥并配置环境变量即可，无需改动代码。

## 一、开通支付宝开放平台沙箱

1. 打开支付宝开放平台并登录（个人可用支付宝账号登录，无需企业认证即可用沙箱）。
   - 控制台：https://open.alipay.com/develop/sandbox/app
2. 首次进入会自动创建一个「沙箱应用」。
3. 在「沙箱应用」页面记下：
   - **APPID**（形如 `9021000123456789`）
   - **沙箱网关**（本项目默认：`https://openapi-sandbox.dl.alipaydev.com/gateway.do`）
   - **沙箱买家账号 / 支付密码**（用于在沙箱收银台完成支付）

## 二、生成密钥并配置到沙箱应用

1. 在沙箱应用页面找到「接口加签方式」→ 选择 **RSA2**。
2. 用支付宝官方工具（沙箱页面内「生成密钥」按钮）或本地命令生成一对密钥。
   本地 Java 环境可用如下命令（Windows 需使用 Git Bash）：

   ```bash
   # 生成应用私钥 + 公钥（PKCS8 格式）
   openssl genrsa -out app_private_key.pem 2048
   openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem
   # 应用私钥通常需转成 PKCS8 无换行字符串给后端
   openssl pkcs8 -topk8 -inform PEM -outform PEM -nocrypt -in app_private_key.pem -out app_private_key_pkcs8.pem
   ```

3. 把**应用公钥**粘贴到沙箱应用的「应用公钥」输入框，保存。
4. 页面会显示 **支付宝公钥**，复制备用。
5. 最终你有三样值：
   - 沙箱 `APPID`
   - 应用私钥（PKCS8，一行字符串）
   - 支付宝公钥（一行字符串）

## 三、配置后端环境变量

后端读取的前缀是 `dufeng.alipay.*`，对应环境变量见下表（大写的 `ALIPAY_*`）。

| 环境变量 | 说明 |
| --- | --- |
| `ALIPAY_ENABLED` | `true` 启用真实支付宝；`false` 退回模拟支付。 |
| `ALIPAY_APP_ID` | 沙箱 APPID。 |
| `ALIPAY_PRIVATE_KEY` | 应用私钥（PKCS8，去掉换行，整个字符串）。 |
| `ALIPAY_PUBLIC_KEY` | 支付宝公钥（去掉换行）。 |
| `ALIPAY_GATEWAY` | 默认即为沙箱网关，无需改动。 |
| `ALIPAY_NOTIFY_URL` | 异步通知地址，需公网可达。本地纯联调可留空，靠轮询查单也能闭环。 |
| `ALIPAY_RETURN_URL` | 支付完成跳回的前端地址，本地：`http://localhost:5173`。 |

### Windows PowerShell 临时演示（在 `backend` 目录、启动前执行）

```powershell
$env:ALIPAY_ENABLED="true"
$env:ALIPAY_APP_ID="你的沙箱AppId"
$env:ALIPAY_PRIVATE_KEY="你的应用私钥"
$env:ALIPAY_PUBLIC_KEY="你的支付宝公钥"
$env:ALIPAY_NOTIFY_URL="http://你的公网地址/api/portal/pay/callback/alipay/notify"
$env:ALIPAY_RETURN_URL="http://localhost:5173"
mvn spring-boot:run
```

### start-local.sh（已被 .gitignore 忽略，可自行加）

```bash
export ALIPAY_ENABLED=true
export ALIPAY_APP_ID="你的沙箱AppId"
export ALIPAY_PRIVATE_KEY="你的应用私钥"
export ALIPAY_PUBLIC_KEY="你的支付宝公钥"
# 无公网回调用轮询也能完成，公网环境建议配置：
export ALIPAY_NOTIFY_URL="http://你的公网地址/api/portal/pay/callback/alipay/notify"
export ALIPAY_RETURN_URL="http://localhost:5173"
```

## 四、重启后端并验证

1. 重启后端（`mvn spring-boot:run`）。
2. 前台登录后下单，进入收银台 `/pay/:orderNo`，选择「支付宝」→ 立即支付。
3. 浏览器会跳转到支付宝沙箱收银台，使用**沙箱买家账号**登录并付款。
4. 付款后跳回 `localhost:5173`，收银台每 4 秒轮询 `/api/portal/pay/{orderNo}/status`，
   后端会主动向支付宝查单并入账，无需公网回调即可完成闭环。
5. 若配置了公网 `ALIPAY_NOTIFY_URL`，支付宝还会异步推送通知到
   `POST /api/portal/pay/callback/alipay/notify`，后端会验签 + 校验 `app_id` + 校验金额 + 幂等入账。

## 五、常见问题

- **提示“支付宝支付未启用”**：`ALIPAY_ENABLED` 未设为 `true`，或环境变量未传递给后端进程。
- **应用私钥格式错误**：需为 PKCS8 无换行字符串；Windows 可先转成 PEM 再手动去掉 `-----BEGIN/END-----` 与换行。
- **签名失败 / 验签失败**：确认「应用公钥」已上传、`ALIPAY_PUBLIC_KEY` 填的是**支付宝公钥**（不是应用公钥）。
- **本地收不到异步通知**：正常，轮询查单已覆盖；公网环境请配置 `ALIPAY_NOTIFY_URL` 并确保公网可达。

> 说明：微信支付同样预留了 `wechat` 渠道，走模拟回调；如需真实微信支付，需商户号 + APIv3 密钥等资质，建议后续单独接入。
